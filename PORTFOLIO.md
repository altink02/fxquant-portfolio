Application implementations are private. Public repositories contain case
studies, interface captures and selected presentation material. A static showcase
is labeled separately from an interactive hosted app. Historical test results
are evidence records, not an assurance that every deployed feature was retested.

The 2026-10-13 review checked public repository links, screenshot references and
selected demo interactions. It also corrected stale author names, account-rename
links and several navigation/status errors. [Review scope and remaining deployment work](REVIEW.md).
